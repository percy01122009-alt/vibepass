Voicefork Android installieren

APK herunterladen

  1. APK herunterladen.
  2. Wenn beim Tippen ZArchiver erscheint: Abbrechen → in Dateien/Downloads die Datei Voicefork-Android.apk suchen → lange drücken oder ⋮ → Öffnen mit → Paketinstaller/App installieren.
  3. Falls nötig: Einstellungen → Apps → Spezieller App-Zugriff → Unbekannte Apps installieren → Browser/Dateimanager erlauben.
  4. App öffnen, Mikrofon erlauben, für Live-Vorschau Kopfhörer nutzen.
